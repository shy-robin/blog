# 个人资料与项目

## 编辑个人资料

访问 `/studio`，从左侧“个人资料”进入单一编辑入口，文档 ID 固定为 `profile`。填写名字、一句话介绍、头像、自我介绍、关注方向、技术经历和可选联系方式，点击 Publish 后显示在 `/about`。

名字和介绍默认沿用博客现有公开身份；没有资料时前台仅展示 ShyRobin、博客定位和已知的 GitHub 地址。不会从 Git 提交记录读取邮箱，也不会自动生成履历。邮箱、城市和公司等字段只有明确填写并发布后才展示，请只填写愿意公开的信息。未填写的经历、关注方向和联系方式会隐藏。

技术经历按后台数组顺序展示，时间说明由作者填写，不自动推断“至今”。自我介绍中段落之间空一行。

## 发布项目

在 `/studio` → “项目”新建记录，填写项目名称、简介，可补充截图、技术栈、职责、个人贡献及源码/演示地址。个人贡献每行一项。展示顺序数字越小越靠前，相同顺序的新项目靠前。

保存草稿不会出现在前台，点击 Publish 后才在 `/projects` 展示。缺少截图、职责或链接时隐藏对应部分；无项目时显示整理中的空状态，不展示虚构项目。外链仅支持 HTTP(S)，不接受脚本 URL 或包含用户名密码的地址。

## 缓存与发布通知

个人资料和项目各使用 60 秒缓存。沿用现有 Webhook 和 Secret，无需新增接口。在 Sanity → API → Webhooks → Edit webhook 中把 Filter 从 `_type == "post"` 改为：

```groq
_type in ["post", "project", "profile"]
```

Projection 保持 `{_type}`，Create / Update / Delete 保持开启。发布个人资料、项目或文章后，接口按内容类型清除 `profile`、`projects` 或 `posts` 缓存。未修改 Filter 时文章发布通知照常工作，项目和个人资料依靠默认缓存刷新。

## 页面与导航

顶部导航为“首页 / 文章 / 项目 / 关于”，当前栏目有选中状态。两页均提供正式域名 canonical、分享信息和 RSS 发现链接，并加入 `/sitemap.xml`。页脚备案与 RSS 入口保留。
